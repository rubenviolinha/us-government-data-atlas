Credential and licensing handoff

What remains after the public releases

Everything below is intentionally deferred until access is available. The existing keyless snapshots remain usable; no secret belongs in the repository.

USPS exact ZIP and address reference

Access: USPS-authorized data agreement or licensed feed.

Why: Census ZCTAs are already included, but delivery-point ZIP geography and address ranges are separately governed.

When available: provide the licensed files or an authorized feed; we can add a restricted ingestion path without committing the raw data.

Census API expansion

Access: Census API key for broad ad hoc variable and geography queries.

Why: the repository already contains extensive keyless ACS bulk snapshots; a key would unlock arbitrary table combinations and future refresh automation.

When available: supply it as a local environment secret (never in Git), then select the desired tables/geographies.

Deeper state archival histories

Access: depends on the state archive or legislature; some sources may require manual downloads or agreements rather than an API key.

Why: current and broad historical official rosters are included where stable public sources exist, but older state-specific office histories are uneven.

When available: identify the states and office histories to prioritize; each source can be normalized with its own provenance rules.

See the machine-readable access requirements registry for the canonical status. Do not send credentials in chat or commit them to GitHub.
