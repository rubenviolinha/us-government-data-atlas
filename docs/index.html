US Government Data Atlas API

A practical, read-only interface over normalized datasets covering geography, people, institutions, elections, climate, public safety, education, health, and more.

Documentation hosting: GitHub Pages hosts this reference site. The Python API is intentionally read-only and runs locally or on a host you control; Pages does not execute the API server.

Quick start

Clone the repository, start the local server, and open the examples below against http://localhost:8000.

python3 api/server.py
# then visit http://localhost:8000/health

No API key is required for the checked-in release files. Source refreshers that need credentials are documented in access requirements.

The same OpenAPI document is available locally at http://localhost:8000/openapi.json.

When self-hosted, the read-only API supports browser clients with permissive CORS and OPTIONS preflight responses.

Release integrity metadata is available at GET /release-manifest, including SHA-256 hashes for every normalized file.

Domain-level inventory and remaining gated inputs are available at GET /coverage.

Endpoint reference

GET /health

Returns a small readiness response.

{"status":"ok","service":"us-government-data-atlas"}
GET / or GET /catalog or GET /datasets

Returns the complete machine-readable catalog, including file paths, record counts, fields, and source URLs.

GET /dataset-groups

Returns logical datasets. Repository-safe _partN shards are combined into one group with aggregate record counts.

GET /dataset-groups/<group>

Combines all shards for a logical group, then applies filters and pagination.

GET /sources

Returns the source registry and provenance notes.

GET /access-requirements

Returns the refreshers that need an API key or other credentials.

GET /datasets/<filename>.json

Streams one catalog-listed normalized file. The filename is relative to data/normalized/.

Filtering and pagination

Dataset endpoints support case-insensitive exact-match filters and text containment filters using the generic field__contains form. Use limit (maximum 1,000) and offset for stable paging.

/datasets/states.json?abbr=CA
/datasets/counties_2023.json?STATEFP=06&limit=25
/datasets/states.json?name__contains=land
/datasets/federal_judges.json?limit=20&offset=40

Responses contain dataset, records, and count. Paginated responses also include limit, offset, and total.
