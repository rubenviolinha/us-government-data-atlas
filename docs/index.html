01 · Quick start

Run the API locally

The checked-in release is keyless. From the repository root:

python3 api/server.py
curl http://localhost:8787/health

The server is read-only and only serves files listed in metadata/catalog.json. It listens on 127.0.0.1:8787 by default; use --host and --port to change that.

03 · Querying

Filters and pagination

Use case-insensitive exact-match query parameters for fields, or use the field__contains form for text search. Pagination accepts limit (1–1,000; default 100) and offset (default 0).

GET /datasets/states.json?abbr=CA
GET /datasets/states.json?name__contains=land
GET /datasets/counties_2023.json?STATEFP=06&limit=25
GET /dataset-groups/nhtsa_recall_campaigns?limit=50&offset=100

List responses use data, count, total, and offset. Group responses also include group and source_urls.

04 · Response contract

Predictable, inspectable JSON

Successful page

{
  "data": [{"...": "..."}],
  "count": 1,
  "total": 52,
  "offset": 0
}

Error

{
  "error": "dataset not found"
}

Invalid pagination returns 400. Unknown datasets and groups return 404. Responses include permissive CORS headers for browser-based self-hosted clients and support OPTIONS preflight.

05 · Data and provenance

What is included

The catalog spans geography, population and demographics, elected officials, elections, agencies, courts, schools, health, crime, climate, transportation, environment, and economic indicators. Every release carries source URLs, retrieval metadata, and a generated catalog entry.

06 · Scope and limits

Read the release notes

This is a versioned snapshot, not a hosted national data service. Refresh dates and source vintages vary by dataset, and source-specific terms remain in force. Historical officeholder coverage is broad where stable public sources exist, but older state-specific histories are uneven.

  • Use /release-manifest to compare file hashes between releases.
  • Use /coverage and /access-requirements to see what is included and what still needs licensed or authenticated access.
  • The Python API is local or self-hosted; GitHub Pages hosts documentation and catalog indexes only.
